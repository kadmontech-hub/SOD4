# SØD Visual MVP v3.0.2

## Canonical panoramic Hub

- Replaced only the main Hub scene with the user-approved panorama.
- Localized the source image at `public/assets/hub/hub-main-360.png`.
- Added drag, touch, keyboard and opt-in gyroscope panoramic navigation.
- Aligned functional hotspots with Hablar con SØD, Biblioteca, Semillas and Observatorio.
- The central Ø opens the cognitive transformation experience.
- Other universes remain accessible through the existing need-based navigation.
- Removed the generated Canvas orb to avoid duplicating the orb already present in the artwork.
- Added a visible startup shell and fatal recovery screen so a runtime error cannot produce a silent black screen.
- Updated the service-worker cache to v3.0.2.
