## Infrastructure placeholders

- Authentication remains local.
- Personal state is stored in the browser.
- No production database is connected.
- No external LLM is connected.
- No production voice provider is connected.
- No blockchain or wallet is active.
- Admin remains a local content demonstration.

## Rule

A placeholder must be visually honest, functionally coherent and explicitly replaceable. It must never be presented as final source material, verified user history or a completed external integration.
