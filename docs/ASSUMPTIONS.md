# Assumptions and boundaries

- The MVP prioritizes immediate executability over adopting a dependency-heavy framework before official assets and production credentials exist.
- Guest mode is the default viable entry.
- WebXR, wallet, marketplace transactions and blockchain ownership remain feature-flagged future capabilities.
- No medical, therapeutic or diagnostic authority is attributed to SØD.
- Official source documents will replace demonstration copy through the content layer.
- The fallback 2D mode is a first-class experience, not an error state.
